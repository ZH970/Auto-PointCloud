PointCloud 工具箱｜项目使用说明书

版本：2026-03-23｜适用平台：Windows

本项目将点云作业流程整合为三段： main.py：TF卡导入 auto.py：Lidar ME自动化 points2SLAM_Output.py：CSV写入Excel

注意：Lidar ME 通常需要管理员权限运行，并确保已插入授权密钥/加密狗。

目录

1. 项目概览 2. 环境安装 3. 快速开始 4. UI三页签说明 5. 推荐流程 6. 常见问题排查 7. 附录（关键路径与参数）

1. 项目概览

1) main.py（导入）

  • 按卷标识别 TF/SD 卡（如 LidarME）
  • 筛选时间戳目录 + 大小范围 + 日期规则
  • 复制到本地并执行重命名策略
  • 创建 after/csv 目录结构供后续步骤使用

2) auto.py（自动化处理）

  • 连接/启动 Lidar ME，执行 UI 操作
  • 可选“执行导入步骤”或“仅后处理”
  • 支持自动识别 pending 或手动指定 pending
  • 包含截图、目标识别、人工选点确认、导出

3) points2SLAM_Output.py（写表）

  • 读取 points.csv
  • 写入目标 Excel 指定 Sheet
  • 支持保留图片列、另存为等参数

2. 环境安装

2.1 安装依赖

cd /d C:\pyprojcet\search-pointcloud-folder
pip install -r requirements.txt

2.2 建议运行方式

  • 建议使用虚拟环境（conda/venv）
  • 建议以管理员方式打开终端/IDE
  • 先手动打开一次 Lidar ME，确认历史任务可见

3. 快速开始

cd /d C:\pyprojcet\search-pointcloud-folder
python ui.py

打开 UI 后，依次执行：

  1. 页签 1：运行 main.py（导入点云）
  2. 页签 2：运行 auto.py（自动化处理）
  3. 页签 3：运行 points2SLAM_Output.py（写入 Excel）

4. UI 三页签说明

4.1 页签一：TF卡导入（main.py）

字段作用
SRC_LABEL设备卷标名（例：LidarME）
SRC_SUBPATH源盘内子路径（空=根目录）
DST本地点云根目录
MIN_MB / MAX_MB按文件夹大小过滤
REQUIRED_MOD_TIME0不筛日期 / 1指定日期 / 2最近7天
REQUIRED_MOD_DATE日期模式=1时使用（YYYY-MM-DD）
NoCopyFolder0实际复制 / 1仅预览
VERBOSE详细日志开关

4.2 页签二：LidarME 自动化（auto.py）

字段作用
ROOT_STR点云工作目录根路径
APP_EXELidar ME 程序路径
自动识别 pending开启后自动扫描今天修改的4位目录
手动输入 pending可填 1172,1173 或绝对路径，分隔符支持逗号/空格/换行
执行导入步骤开启：新建任务+选文件夹+RTK+确认；关闭：仅后续处理

4.3 页签三：写入 Excel（points2SLAM_Output.py）

字段作用
points.csv 路径支持单个或多个（按当前脚本参数组织）
Excel 工作簿路径目标 xlsx 文件
Sheet 名称写入工作表名（默认 SLAM扫描测试）
另存为可空；空时按脚本默认策略处理
保留图片列控制图片列处理策略（默认 1）

4.4 通用按钮

  • 运行：启动对应脚本并传入 UI 配置（环境变量）
  • 停止：终止对应子进程（terminate，必要时 kill）
  • 保存配置：写入 ui_config.json，下次自动回填

5. 推荐作业流程

  1. 插入 TF 卡，页签1运行 main.py 完成导入与目录命名。
  2. 页签2运行 auto.py：
    • 新任务首次处理：勾选“执行导入步骤”
    • 已导入任务复跑：取消“执行导入步骤”并手动指定 pending
  3. 页签3运行 points2SLAM_Output.py，将 points.csv 写入 Excel。

6. 常见问题排查

6.1 UI 日志乱码 / 看不到中文

  • 原因：Windows 子进程输出编码混合（UTF-8/GBK）。
  • 建议：UI 采用字节流读取并 utf-8/gb18030 回退解码（已在 ui.py 中实现）。

6.2 Lidar ME 打开后没有历史任务

  • 建议先手动启动 Lidar ME，确认任务数据库正常，再用自动化连接。
  • 如自动启动目录不一致，可能导致加载到不同工作环境。

6.3 send_keys 路径输入报 Unknown code

  • 常见原因：对路径做了重复转义（括号/反斜杠二次 escape）。
  • 处理原则：路径先规范化，再只在 send_keys 前转义一次。

6.4 Excel 写入报 no such item '/xl/worksheets/sheet1.xml'

  • 原因：zip 路径前导斜杠不一致。
  • 处理：对关系 Target 做归一化，去掉前导 / 再读取。

6.5 “查看”按钮灰色导致 auto 无法继续

  • 原因：任务未完成导入，按钮尚不可点击。
  • 建议：重试时每轮重新定位任务并重新点击打开，而不是只调用 solve。
